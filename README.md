# The House Always Wins 🎰

**The House Always Wins**, Unity 3D motoru ile geliştirilmiş risk ve ödül tabanlı, interaktif bir casino yönetimi ve simülasyon oyunudur. Oyuncular casino içindeki güvenliği sağlar, yapay zeka yönlendirmeli müşterileri takip eder ve şüpheli durumlarda "Sorgu Odası" (Interrogation) mekaniği ile kritik kararlar alarak casinonun ekonomisini yönetirler.

## ⚙️ Kurulum Talimatları (Setup Instructions)
Projeyi yerel makinenizde çalıştırmak için aşağıdaki adımları izleyin:
1. Bu depoyu (repository) bilgisayarınıza klonlayın:
   `git clone https://github.com/BerkayHalicioglu/TheHouseAlwaysWins.git`
2. **Unity Hub** uygulamasını açın.
3. `Open` butonuna tıklayın ve klonladığınız proje klasörünü seçin.
4. Proje yüklendikten sonra `Assets/_Scenes` klasörü altındaki ana oyun sahnesini açın.
5. Unity Editor üzerinden **Play** tuşuna basarak oyunu başlatın.

## 🎮 Oyun Kontrolleri (Controls)
* **W, A, S, D:** Karakter Hareketi
* **Mouse:** Kamera Kontrolü / Etrafa Bakma
* **E:** Objelerle ve NPC'lerle Etkileşim (Sorgu ekranını başlatma)
* **Sol Click:** UI Menülerinde ve Sorgu Odasında Seçim Yapma (Suçlu/Masum kararları)
* **ESC:** Oyunu Durdurma / Menü
